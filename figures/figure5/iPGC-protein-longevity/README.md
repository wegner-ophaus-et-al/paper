# Nucleus Reporter Fluorescence — Normalization & Plotting

Normalizes and plots nuclear fluorescence intensities from a zebrafish primordial
germ cell (PGC) reporter assay. Three co-injected reporter mRNAs — eGFP–dnd1,
mScarlet-i–nanos3, and tagBFP–globin 3′UTR constructs (globin serving as the
injection control) — are measured across developmental stages (10–72 hpf) in
embryos with (`full_mix`) or without (`no_tdrd7`) tdrd7. The script computes
dnd/globin and nanos/globin fluorescence ratios, normalizes them to the
`full_mix` mean at each stage, plots the results, and runs per-stage
statistical comparisons between conditions.

## Input data

The script reads only **`data/nucleus.csv`** (398 rows), with columns:

| Column | Description |
|---|---|
| `Repeat` | Replicate/embryo ID |
| `stage` | Developmental stage: `10hpf`, `24hpf`, `48hpf`, `72hpf` |
| `globin` | Raw tagBFP-globin fluorescence intensity (injection control) |
| `dnd` | Raw eGFP-dnd1 fluorescence intensity |
| `nanos` | Raw mScarlet-i-nanos3 fluorescence intensity |
| `condition` | `full_mix` (control) or `no_tdrd7` (tdrd7 knockdown) |

Intensities come from quantification of fluorescence microscopy images.

Other files in `data/` are earlier/raw stages of this same dataset, kept for
provenance but not read by any script here: `data/nucleus_streamlined.xlsx`
(the Excel export `nucleus.csv` was derived from), `data/iPGC intensities.xlsx`
(the raw per-stage measurement workbook), and `data/Graphs without outliers.pdf`
(an earlier exported figure predating this plotting script).

## How to run

No environment file (`requirements.txt`/`environment.yml`) is currently
included in this repo. The script depends on:

- `pandas`
- `matplotlib`
- `seaborn`
- `scipy`

(no versions pinned — install current versions of each, or add a
`requirements.txt` if you need reproducible pins).

Then, from the repo root:

```bash
python nucleus_plotting.py
```

Paths are resolved relative to the script location, so it must be run with
`data/` and `output/` present alongside `nucleus_plotting.py`.

## Key files

- **`nucleus_plotting.py`** — loads `data/nucleus.csv`, computes normalized
  fluorescence ratios, runs per-stage statistical comparisons, and generates
  the figure and stats output.
- **`utils.py`** — statistics helpers: `parametric` (normality check via
  `scipy.stats.normaltest`), `statistical_analysis` (t-test or Mann-Whitney U
  depending on normality), and `get_stars` (p-value → significance stars).
