Statistical significance between groups was assessed in Python (SciPy v1.x) using a two-step, distribution-aware procedure. For each pairwise comparison, normality of both samples was first evaluated using D'Agostino and Pearson's omnibus test (scipy.stats.normaltest); both distributions were required to satisfy p > 0.05 to be considered normally distributed. When this criterion was met, group means were compared using an unpaired two-tailed Student's t-test (scipy.stats.ttest_ind); otherwise, the non-parametric Mann-Whitney U test (scipy.stats.mannwhitneyu) was used to avoid assumptions of normality. Resulting p-values are reported directly and denoted on plots using conventional significance thresholds (*p < 0.05, **p < 0.01, ***p < 0.001; ns, not significant).
