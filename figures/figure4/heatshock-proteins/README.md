# Stress Granule Markers — Segmentation & Analysis Pipeline

Quantitative analysis of stress granule formation in fluorescence microscopy images of heat-shocked cells. The pipeline uses a SAM-based segmentation model to detect stress granules and computes per-cell metrics across control vs. heat-shock conditions for multiple genetic constructs.

## What It Does

1. **Preprocessing** (`crop_original_raw.py`): Crops raw multichannel TIFF stacks to individual cell masks and produces per-channel intensity images (NLS, stress marker, granulito/granule marker).

2. **Granule Segmentation** (`segmenter.py` + `processor.py` + `perform_granule_semgentations.py`): For each sample, reads the three channel images and a cell mask, runs a fine-tuned SAM (`micro_sam`) model to segment granules, then computes:
   - Areas: total cell, granule, and cytoplasm
   - Mean intensities of granulito and stress marker within cell, granules, and cytoplasm
   - Ratio of cytoplasmic-to-granule stress marker intensity

3. **Visualization & Statistics** (`perform_granule_semgentations.py`): Generates a summary PDF of all sample segmentations, a publication-style point plot (control vs. heatshock per construct), and performs per-construct statistical tests (t-test or Mann-Whitney U depending on normality) for key features. Representative sample IDs near the median are exported.

## Data Structure

### Folder Hierarchy (per sample)
```
{construct}/
  {uid}__{sample_name}/
    images/
      gra.tif          # granulito channel (max-projected, 16-bit)
      nls.tif          # NLS nuclear channel
      stress.tif       # stress marker channel
    masks/
      cell.tif         # cell segmentation mask (from ImageJ)
      granules.tif     # granule segmentation mask (generated by pipeline)
```

### Per-Sample Result Record
| Field | Description |
|---|---|
| `uid` | Unique sample identifier |
| `sample_name` | Human-readable sample name |
| `construct_id` | Genetic construct (e.g. F617, F618) |
| `condition` | `"control"` or `"heatshock"` |
| `total_cell_area` | Cell area in pixels |
| `total_granules_area` | Granule area in pixels |
| `total_cytoplasm_area` | Cytoplasm area in pixels (cell − granules) |
| `mean_int_granulito_cell` | Mean granulito intensity over whole cell |
| `mean_int_granulito_granules` | Mean granulito intensity within granules |
| `mean_int_granulito_cytoplasm` | Mean granulito intensity in cytoplasm |
| `mean_int_stress_marker_cell` | Mean stress marker intensity over whole cell |
| `mean_int_stress_marker_granules` | Mean stress marker intensity within granules |
| `mean_int_stress_marker_cytoplasm` | Mean stress marker intensity in cytoplasm |
| `mean_int_ratio_stress_cytoplasm_to_granule` | Derived: cytoplasm / granule stress intensity |

### Code Layout
| File | Role |
|---|---|
| `segmenter.py` | `SegmentationModel` (SAM wrapper) and `SegmentationInstance` (image + result) classes |
| `processor.py` | `process_sample()` — the per-sample analysis logic |
| `perform_granule_semgentations.py` | **Main entry point** — orchestrates the full pipeline |
| `crop_original_raw.py` | Preprocessing: crop and project raw multichannel stacks |
| `utils/utils.py` | Utilities: image I/O, normalization, upsampling, statistics |
| `unknown.py` / `unknown.ipynb` | Experimental random-walker segmentation (not integrated) |
| `imageJ_macros/` | ImageJ macros for manual cell mask generation |
